## Herdr

Update:
`herdr update`

### Server

| Function             | Command                       |
|----------------------|-------------------------------|
| Stop Server          | `herdr server stop`           |
| Reload config        | `herdr server reload-config`  |



### Hotkeys

| Function                     | Keys                  |
-------------------------------|------------------------
