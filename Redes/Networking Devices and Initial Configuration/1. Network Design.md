# Reliable Networks
## Network Architecture
With so many people in the world relying on network access, it is imperative that networks are reliable. In this context, reliability means more than your connection to the internet.
The role of the network has changed from a data-only network to a system that enables the connections of people, devices, and information in a media-rich, converged network environment. For networks to function efficiently and grow in this type of environment, the network must be built upon a **standard network architecture**.

As networks evolve, we have learned that there are four basic characteristics that network architects must address to meet user expectations:
- Fault Tolerance
- Scalability
- Quality of Service (QoS)
- Security
## Fault Tolerance
A fault tolerance network is one that limits the number of affected devices durint a failure. It is built to allow quick recovery when such a failure occurs. **These networks depend on multiple paths** between the source and destination of the package. If one path fails, the package are instantly sent over a different link. 

Implementing a packet-switched network is one way that reliable networks provide redundancy. **Packet switchting** splits traffics into packets that are routed over a shared network. A single message, such an email, is **broken into multiple message blocks**, called **packets**.
![[redundant_network_topology_transparent.png]]
> In the figure, the user is unaware and unaffected by the router that is dinamically cally changing the route when a link fails

Each packet has the necessary addressing information of the source and destination of the message. The **router** within the network switch the packets based on the condition of the network at that moment.
## Scalability
A scalable network expands nds quickly to support new users and application. It does this without degrading the perfomance of services that are being accessed by existing users.

![[scalability_network_topology_transparent.png]]
> In the figure, it shows how a new network is easily added to an existing network.

These networks are scalable because the designers follow accepted standards and protocols. This lets software and hardware vendors focus on improving products and services without having to a design a new set of rules for operating within the network.
